# Avatar

Initials on a black disc in gold letters: the one avatar treatment in Clean Space.

## Props

- `initials`: one or two letters.
- `size`: `'xs'` 20px (9px letters), `'sm'` 28px (10px, the default), `'md'` 36px (12px), `'lg'` 48px (16px).
- `variant`: 1 to 5. All five resolve to `color-brand-primary-500` in Clean Space (owner call, 2026-08-16: black background, gold lettering for everyone), so the number no longer changes the colour.

## Look

A `badge-radius` disc with weight-600 letters in `color-brand-secondary-500` (gold on the black holds 14:1). No photos.
