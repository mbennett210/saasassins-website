# Logos

The CleanSpace mark and lockups, copied unchanged from the app (`app/public`) and its brand pack (`brands/cleanspace`, where the two sources live; `npm --prefix app run brand` draws the PNGs from them). Use these files; never redraw, recolour or rebuild the mark.

- `cleanspace-logo.png` (788×99, transparent): the white lockup, the CS mark with the "CleanSpace" wordmark. Dark grounds only: it heads the black sidebar rail (`color-brand-primary-700`). Ink: white.
- `cleanspace-glyph-ink.png` (540×328, transparent): the CS mark alone in `#09090b` (`color-brand-primary-700`). For light grounds; the phone's floating nav uses it.
- `cleanspace-logo-src.jpg` (1080×228, white background): the source lockup with the line "An Alliance Building Services Company". The reference the app's logos were made from; the app itself shows the PNGs.
- `cleanspace-mark.png` (8001×4501): the high-resolution source mark, white on a `#101820` navy-black field. For large and print use.

The wordmark sets "CleanSpace" as one word; running text and the app's title say "Clean Space".
