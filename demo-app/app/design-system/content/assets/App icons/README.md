# App icons

The installable-app (PWA) icon set, generated from the real mark: a white CS on the brand black `#18181b` (`color-brand-primary-500`). The web manifest's theme and background colour is the same black.

- `icon-512.png` and `icon-192.png`: the rounded-square app icon (transparent corners), manifest purpose "any".
- `icon-maskable-512.png`: full-bleed black with the mark inside the safe zone, manifest purpose "maskable".
- `apple-touch-icon.png` (180×180): the iOS home-screen icon.
- `favicon.png` (48×48): the browser tab icon.

The app's name on a home screen is "Clean Space".
